# Swarm — 撒网模式

> 同一个任务交给多个 agent 独立完成（互盲），Leader 从中选最优。
> 用多路冗余换质量。

## 立场

Swarm 的逻辑是「不知道谁最擅长，就都试一遍」。
每个 agent 收到完全相同的 Brief，独立产出，互不可见。
Leader 最后当裁判，选出最优或综合最优部分。

## Leader 流程

```
[1] 派子任务（所有子任务同时派出，Brief 完全相同）
    ├─ 每个子任务的 description = 父单 Brief 原文
    ├─ 不要告诉他们「还有其他人在做同样的事」
    │
[2] 所有子任务交回
    ├─ 逐个阅读每份产出
    │
[3] 评选
    ├─ 按 Brief 里的 Goal/追踪目标作为评选标准
    ├─ 在 timeline 写出评选理由：
    │   「s1 的产出在 X 维度最强，s2 在 Y 维度更好，综合选 s1」
    │
[4] 交回
    ├─ 将选中的产出（或综合版）写入 timeline
    └─ 置 review 交回
```

## Brief 应包含

- 任务描述（所有参与者会收到完全相同的内容）
- 评选标准（什么算"好"——准确性/创意/深度/实用性）
- 可选：期望产出的格式

## 禁止

- 子任务之间不得互相看到（互盲，比 split 更严格）
- Leader 不得在评选前给任何子任务额外提示
- 评选必须有理由，不得「随便选一个」
